# Концепт нового інтерфейсу

Файл `concept/ref-board-concept.html` є **статичним макетом** нового інтерфейсу: один HTML без JavaScript (0 тегів `<script>`). Перемикання вкладок, чіпсів і карток зроблено через приховані `radio` і `checkbox` з `label`, тож макет можна відкрити без сервера і він не зберігає жодних даних. Скриншоти поруч: `concept/ref-board-concept.png` (загальний вигляд), `concept/ref-board-concept_tab-theses.png` (вкладка «Тези»), `concept/ref-board-concept_tab-colors.png` (вкладка «Колір»).

Макет показував цільовий вигляд v1; тепер він реалізований у `ref-board.html` (див. таблицю нижче).

## Важливо: зображення не входять до репозиторію

Макет використовує власні зображення з `concept/assets/` (зменшені приклади UI, 7 файлів), тож відкривається без зовнішніх залежностей. Скриншоти `*.png` зроблено з нього через headless Chrome.

## Розкладка

- **Ліворуч: список референсів.** Заголовок з кнопками «Оновити», «Змінити папку», «Додати файли». Кожен рядок: мініатюра, назва, статус (●, ◐, ○), мітка «нове», кількість тез. Внизу кнопки «Експорт JSON» і «Імпорт JSON».
- **Праворуч: картинка зверху на всю ширину.** Під нею панель редагування. Інструмент перемикається між «Виділити» і «Піпетка» (радіокнопки над зображенням), масштаб зліва зверху (вмістити, 100 %, ±).
- **Під картинкою: три вкладки.**
  1. **Тези по областях.** Список тез поточного референсу з номерами, заголовком, нотаткою «Чому?» і категорією та вердиктом чіпсами. За макетом, вибрана теза підсвічується на картинці (у прототипі це вже працює).
  2. **Загальна оцінка.** Великі картки критеріїв (Колір, Шрифт, Компоненти, Сітка, Настрій). Коментар розгортається тільки в обраній картці.
  3. **Колір.** Кнопки «Витягнути з усієї картинки», «Витягнути з виділення №N», «Піпетка: додати колір». Далі палітра з ролями і перевіркою контрасту (див. етап 3).

Метадані референсу (ім'я, розмір, статус) в одному тонкому рядку над картинкою.

## Чіпси замість дропдаунів

Категорії й вердикти вибираються чіпсами з емодзі, а не випадаючими списками. Це видно одразу і не вимагає клікнути, щоб дізнатися поточне значення.

| Група | Варіанти |
|---|---|
| Категорія тези | 🎨 Колір · 🔤 Шрифт · 🧩 Компонент · 📐 Сітка · ✨ Настрій |
| Вердикт | 👍 Беру · 😐 Нейтрально · 👎 Уникаю |
| Підказки (сірі чіпси) | для кольору: «контраст», «акцент», «баланс»; для компонентів: «вага», «відступи», «ритм» |
| Шрифт | окремий тумблер «Шрифт цікавий» |

Підказки є лише швидкими тегами для вибору критерію. Вони не замінюють коментар.

## Картки загальної оцінки

- Кожна картка має ілюстрацію критерію, назву і статус: «не обрано» (сірий стан за замовчуванням), вердикт з емодзі (👍 Беру, 😐, 👎 Уникаю) або «обрано» для шрифту.
- Стан «не обрано» відрізняє «не оцінював» від «нейтрально» (див. [PLAN.md](PLAN.md), розділ 7а).
- Поле «Чому?» (одне речення) зʼявляється в обраній картці. Це пояснення, чому прийом працює, яке потрібне агенту для узагальнення.
- Тестові тексти в макеті («Тестовий коментар: синій лише для активного», «Пігулка і картка в одній вазі розмивають ієрархію») показують формат, а не реальні дані.

## Стиль

Нейтральний, як у прототипі: токени в `:root` (`--bg #f4f5f7`, `--panel #ffffff`, `--line #e2e5eb`, `--text #1d2330`, `--muted #6b7385`, `--accent #3b6fe0`, `--take #1f9d55`, `--avoid #d64545`), системний шрифт, 13 px, радіус 8 px. Світла тема, без перемикача тем (рішення з плану).

## Рішення (узгоджено)

- Список референсів зліва, один широкий робочий простір праворуч (картинка і редагування під нею).
- Вкладки замість однієї довгої панелі: тези, загальна оцінка і колір не конкурують за місце.
- Чіпси з емодзі для категорій і вердиктів.
- Великі картки оцінки з коментарем лише в обраній картці.
- Нейтральна світла тема без перемикача.
- Зведеного підсумку по всіх референсах у v1 немає.
