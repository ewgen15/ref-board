# Формат даних (JSON), version 2

Формат відповідає коду `ref-board.html` (`normalizeRef`, `normalizeImport`, `buildExport`). Версія 1 (прототип) імпортується з автоматичною міграцією; нижче опис версії 2 і правил міграції.

## Верхній рівень

```json
{
  "version": 2,
  "exportVersion": 1,
  "exportedAt": "2026-11-12T12:44:16.116Z",
  "references": [ /* записи */ ]
}
```

| Поле | Тип | Опис |
|---|---|---|
| `version` | число | версія схеми. Імпорт приймає `1` і `2`, інші відхиляє. |
| `exportVersion` | число або `null` | номер із імені файлу (`vNNN`); `null` у резервному експорті в Downloads; у старих файлах поля може не бути |
| `exportedAt` | рядок ISO 8601 (UTC) | момент експорту |
| `references` | масив | усі записи (також ті, для яких файлу зараз немає) |

Імʼя файлу: `ref-board_vNNN_РРРР-ММ-ДД_ГГХХ.json` (локальний час). «Експорт для аналізу» додає поруч каталог `ref-board_vNNN_crops/`.

## Запис референсу

```json
{
  "id": "Example.webp|137652|1794479215994",
  "name": "Example",
  "file": { "name": "Example.webp", "w": 2048, "h": 1536 },
  "source": "", "tags": [],
  "comment": "Загальне враження.",
  "highlights": [ { "id": "hmwd...", "rect": {"x": 72.65, "y": 66.55, "w": 24.81, "h": 29.92},
    "title": "Число як герой", "note": "...", "why": "Без цього екран читається як список",
    "category": "font", "verdict": "take", "crop": "ref-board_v003_crops/Example.webp_137652_1794479215994_hmwd.png" } ],
  "palette": [ { "hex": "#e6e3db", "share": 0.52, "role": "background", "source": "auto" } ],
  "font": { "interesting": true, "note": "" },
  "ratings": {
    "color": { "selected": true, "verdict": "take", "reasons": ["контраст", "акцент"], "note": "", "score": null },
    "font": {}, "components": {}, "grid": {}, "mood": {}, "icons": {}
  },
  "takeaways": { "generatedAt": null, "tokens": {}, "rules": [], "avoid": [] }
}
```

| Поле | Тип | Примітки |
|---|---|---|
| `id` | рядок | ключ файлу `імʼя\|розмір\|lastModified`; можна змінити привʼязкою до іншого файлу |
| `name`, `file.*` | рядок, число або `null` | відображення; `file.w/h` заповнюються після завантаження картинки |
| `source` | рядок | джерело (URL, сайт); поле вводу в рядку метаданих |
| `tags` | масив рядків | довільні теги |
| `comment` | рядок | загальний коментар референсу |
| `font` | обʼєкт | `{interesting, note}`; тумблер у картці «Шрифт» |
| `takeaways` | обʼєкт | зарезервовано (етап 4), не заповнюється |

Поля `status` більше немає: статус обчислюється (див. нижче). Невідомі верхньорівневі поля при імпорті зберігаються.

## Виділення (`highlights[i]`)

| Поле | Тип | Значення |
|---|---|---|
| `id` | непорожній рядок, унікальний у записі | |
| `rect` | `{x, y, w, h}` | відсотки 0-100, скінченні числа, `w,h > 0`, `x+w` і `y+h` не більше 100 |
| `title`, `note`, `why` | рядок | заголовок, нотатка, «чому це працює» |
| `category` | `color`, `font`, `component`, `grid`, `mood` | інше значення -> `component` |
| `verdict` | `take`, `neutral`, `avoid` | інше значення -> `neutral` |
| `crop` | рядок або `null` | лише в «Експорті для аналізу»: відносний шлях до PNG; у збережених даних не зберігається, при імпорті ігнорується |

Некоректні виділення (немає `id`, немає або хибний `rect`, дубль `id`) відкидаються при імпорті й завантаженні сховища з повідомленням про кількість.

## Оцінка (`ratings`)

Ключі: `color`, `font`, `components`, `grid`, `mood`, `icons`. Кожен:

| Поле | Тип | Значення |
|---|---|---|
| `selected` | булеве | картка обрана; `false` = «не обрано» (відрізняється від «нейтрально») |
| `verdict` | `take`, `neutral`, `avoid` | за замовчуванням `neutral`; має зміст лише при `selected` |
| `reasons` | масив рядків | чіпси-причини (по 4 запропоновані на картку, наприклад «контраст», «акцент», «баланс», «палітра» для кольору) |
| `note` | рядок | коментар (поле видно лише в обраній картці) |
| `score` | число або `null` | успадковано з v1; у UI не показується, зберігається |

При знятті вибору з картки з коментарем або причинами показується підтвердження; вердикт, причини і коментар очищаються, `score` лишається.

## Палітра (`palette[i]`)

| Поле | Тип | Значення |
|---|---|---|
| `hex` | `#rrggbb`, нижній регістр | |
| `share` | число 0-1 або `null` | частка площі; `null` для піпетки і ручних кольорів |
| `role` | `background`, `surface`, `accent`, `textPrimary`, `textSecondary`, `other` | лише підказка, змінюється вручну |
| `source` | `auto`, `selection`, `eyedropper`, `manual` | звідки колір |
| `removed` | `true` (необовʼязково) | фон, вилучений із розрахунку решти |
| `from` | рядок (необовʼязково) | `id` виділення при `source: "selection"` |

Нове витягування замінює кольори `auto` і `selection`, а `eyedropper` і `manual` лишає. Зміну можна скасувати (Ctrl+Z або тост).

## Статус референсу (обчислюється)

- ● оцінено: обрано щонайменше 2 картки і є хоча б одна теза або загальний коментар;
- ◐ в процесі: є будь-які дані (тези, коментар, вибрані картки, шрифт, палітра, джерело, теги);
- ○ нове: даних немає.

## Міграція v1 -> v2

| v1 | v2 |
|---|---|
| `ratings.color` | `ratings.color` |
| `ratings.typography` | `ratings.font` |
| `ratings.layout` | `ratings.grid` |
| `ratings.components`, `ratings.mood` | без змін |
| (немає) | `ratings.icons` (порожня), `reasons: []`, `selected` |
| `ratings.*` з `score`, непорожнім `note` або `verdict != neutral` | `selected: true`; `score` лишається |
| `highlights[].category` `typography` / `layout` | `font` / `grid` |
| (немає) | `highlights[].why = ""`, `palette[].source = "auto"` |
| `status` | відкидається (статус обчислюється) |

Міграція ідемпотентна (перевіряється самотестом). Сховище `localStorage` (`ref-board:v1`) містить `{version: 2, refs, scanIds, newIds, folderName}`; старі дані з `version: 1` читаються й мігруються, перед цим один раз зберігається резерв `ref-board:v1:backup-v1`.

## Імена файлів кропів

`<refId>_<hlId>.png`, де `refId` і `hlId` очищені від символів `\ / : * ? " < > |` і пробілів (замінені на `_`, до 100 символів). Кроп вирізається з повного зображення за `rect`.

## Сумісність

- Імпорт приймає `version` 1 і 2; запис із тим самим `id` повністю замінюється (з підтвердженням).
- Усі імена полів англійські, тексти користувача українські. Дати в ISO 8601.
